## Currently learning

📚 **Linear algebra** and **data structures & algorithms**.

- **Span** is every vector you can reach by scaling and adding a set of vectors together — the "territory" they cover.
- **Basis** is the smallest set of independent vectors that still covers that whole territory, with no redundant directions.
- A LoRA update is `ΔW = B·A` with rank *r*, so it can only move the model's weights inside an *r*-dimensional subspace — the LoRA learns a small basis of "style directions."
- That makes rank a real design choice for my art LoRAs: too low and a style like my gouache portraits can't be captured; too high and it memorises my small dataset instead of learning the style.
